# 产品说明

## 1. 产品定位

“和 QQ 的周末小冒险”是一份可以互动的约会邀请。它不是冷冰冰的排期表，而是让朋友在一段轻松、可爱的童话体验里完成约会选择。

核心目标：

1. 让被邀请的人愿意完成预约，而不是面对复杂表单。
2. 清楚表达 QQ 的可约时间，避免来回确认。
3. 提交后双方都能获得明确、有仪式感的结果。
4. QQ 能从邮件中直接知道是谁、什么时候、想做什么。

## 2. 目标使用场景

QQ 将公开链接发给一位或多位朋友。朋友使用手机打开页面，独立提交自己的预约。每次提交都会产生新的预约编号，并向 QQ 发送一封邮件。

当前页面不要求登录，也不收集手机号。申请人只需填写名字或昵称，用于区分是谁发起了预约。

## 3. 完整体验流程

### 第零章：接受邀请

首页问题为：

> 你愿意周末和QQ一起出去玩耍吗？

- “愿意呀”进入日期选择。
- 否定按钮在前三次接近或点击时会移动，并变换文案。
- 第三次之后可以真正拒绝，页面会温柔结束，而不是强迫接受。
- 拒绝后仍可重新查看邀请。

### 第一章：选择日期和时间

- 日历只允许选择周五、周六和周日。
- 从次日后的第一个可约日期开始，最多展示约 70 天。
- 周一至周四显示为不可选，表达 QQ 正在上班。
- 选择日期后才出现对应时间段。

当前时间配置：

| 日期 | 可选时间 |
| --- | --- |
| 周五 | 21:00、21:30、22:00、22:30、23:00 |
| 周六、周日 | 10:30、13:00、15:30、18:00、20:30 |

### 第二章：填写申请人与活动

申请人必须填写名字或昵称，最长 24 个字符。该名字会出现在：

- 提交前的核对页
- QQ 收到的邮件标题和正文
- 最终生成的邀请函

可选活动：

| 活动 | 页面描述 |
| --- | --- |
| 看电影 | 挑一部不会睡着的电影 |
| 一起吃饭 | 把好吃的都分你一口 |
| 看展 | 认真或假装认真地看艺术 |
| 小酌一杯 | 慢慢聊到晚风都困了 |
| 交给 QQ | 保留一点未知的惊喜 |
| 其他计划 | 写下脑海里的秘密路线 |

选择“其他计划”时，自定义内容为必填。申请人还可以填写一段可选悄悄话，例如口味、天气、地点偏好或其他说明。

### 第三章：核对与提交

核对页展示申请人、日期、时间、活动和悄悄话。只有必填信息完整时才能进入该页面。

点击“确认预约并告诉 QQ”后：

1. 页面生成格式为 `QQ-日期-四位随机数` 的预约编号。
2. 预约信息通过邮件服务发送给 QQ。
3. 发送成功后进入邀请函页面。
4. 发送失败时保留所有选择，并允许再次提交。

### 完成页：获得邀请函

完成页以正式邀请函呈现申请人、日期、时间、活动、悄悄话和预约编号，并提供：

- 保存邀请函：将邀请函导出为 PNG 图片。
- 加入日历：下载一个两小时的 `.ics` 日历事件。
- 分享：调用手机系统分享；不支持时复制文字与链接。

## 4. 视觉与语气

视觉方向来自《爱丽丝梦游仙境》的感觉，但不直接使用受版权保护的角色形象。页面使用复古植物、钥匙、纸张、印章、浆果红、叶绿色与粉蓝色，形成旧绘本和秘密花园的氛围。

文字语气保持温柔、俏皮、有仪式感，避免像商务预约系统。交互有玩笑感，但最终仍尊重访客真正拒绝的选择。

## 5. 数据与隐私

当前会处理以下内容：

- 名字或昵称
- 预约日期与时间
- 活动计划
- 可选悄悄话

网站不建立用户账户，也不把预约写入本站数据库。提交内容会发送给第三方邮件服务 FormSubmit，再投递到 QQ 的收件邮箱。公开分享链接时，应避免让朋友在悄悄话里填写敏感个人信息。

## 6. 当前限制

- 多位朋友可以选择同一时间，系统不会自动检查冲突。
- 页面无法查询历史预约，也没有 QQ 专用管理后台。
- 预约提交后不能从页面修改或取消。
- 邮件送达依赖 FormSubmit 和收件邮箱的反垃圾策略。
- 周末“全天可约”目前通过五个固定时间点表达，并非任意时间输入。

## 7. 推荐的下一阶段

优先级从高到低：

1. 增加预约数据库与 QQ 专用查看页，集中管理全部邀请。
2. 已被预约的时间自动置灰，避免撞期。
3. 增加“已确认、需协商、已取消”状态与回复入口。
4. 允许 QQ 在管理页临时关闭某个周末或新增特殊时间。
5. 增加提交成功后的自动回执邮件，让申请人也保留文字版确认。
